HOW TO RUN
----------
Simply open index.html in any modern web browser.
No installation, build tools, or server required.

FEATURES
--------
1. Modern, responsive design (mobile-first)
2. Sticky navigation with mobile hamburger menu
3. Full-screen hero section with animations
4. Team introduction with value cards
5. Candidate grid with profile modals
6. Vision section with 8 editable cards
7. Manifesto with expandable accordions
8. Campaign updates with load more functionality
9. Image gallery with category tabs and lightbox
10. Election information section
11. Contact form with validation
12. Back-to-top button
13. Scroll reveal animations
14. Current year auto-update in footer
15. Full keyboard accessibility
16. Reduced motion support
17. Lazy loading for images
18. Image error fallbacks

CUSTOMIZATION
-------------
COLORS: Edit CSS variables in style.css :root section
CONTENT: Edit placeholder text in index.html and data arrays in script.js
IMAGES: Replace placeholder images in images/ folder
